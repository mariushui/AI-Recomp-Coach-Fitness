## a) Trainingseinheiten und Splits

| Begriff | Definition |
|---|---|
| Push (Drücken) | Einheit für Brust, Schultern (vorn, seitlich) und Trizeps. |
| Pull (Ziehen) | Einheit für Rücken (Latissimus, oberer Rücken), hintere Schulter und Bizeps. |
| Beine / Unterkörper (Legs, Lower) | Einheit für Quadrizeps, Beinbeuger, Gesäß, Waden, oft auch Adduktoren. |
| Oberkörper (Upper) | Einheit für alle Muskeln des Oberkörpers, also Push und Pull zusammen. |
| Ganzkörper (Full Body) | Einheit, die alle großen Muskelgruppen trainiert. Meist 2 bis 4 Mal pro Woche. |
| Upper/Lower | Split im Wechsel Oberkörper und Unterkörper, meist 4 Einheiten pro Woche, jeder Muskel 2 Mal. |
| PPL (Push/Pull/Legs) | Split aus Push, Pull und Beine. 3 Einheiten (jeder Muskel 1 Mal) oder 6 Einheiten (2 Mal) pro Woche. |
| Bro-Split | Ein Muskel pro Tag (Brust, Rücken, Schultern, Arme, Beine). Jeder Muskel meist 1 Mal pro Woche. |
| Torso/Limbs | Split im Wechsel Rumpf (Brust, Rücken, Schultern) und Gliedmaßen (Arme, Beine). Hubermans Plan ähnelt dem (H1). |
| Arme und Waden | Eigene kurze Einheit für kleine Muskeln, bei Huberman samstags mit Nacken (H1). |
| Zone 2 / Ausdauer lang | Lockere Ausdauer, bei der man noch sprechen kann. Bei Huberman 60 bis 75 min (H1). |
| HIIT | Hochintensives Intervalltraining, kurze Belastung mit kurzer Pause (H1). |
| Konditionstraining | Ausdauer oder gemischte Belastung ohne Hypertrophieziel (H6). |
| Deload-Woche | Woche mit reduziertem Volumen oder reduzierter Intensität zur Erholung (Nr. 8). |
| Frequenz | Wie oft ein Muskel pro Woche trainiert wird. Für Hypertrophie bei gleichem Volumen wenig relevant (Nr. 13). |
| Direkter / indirekter Satz | Direkt: Zielmuskel ist Hauptakteur. Indirekt: Muskel arbeitet mit (zum Beispiel Trizeps beim Bankdrücken). Zählung 1,0 und 0,5 (Nr. 13). |

## b) Bewegungsmuster

| Muster | Definition | Beispiele |
|---|---|---|
| Horizontal drücken | Last vom Körper weg, senkrecht zum Rumpf. | Bankdrücken, Liegestütz |
| Vertikal drücken | Last über den Kopf. | Military Press, Kurzhantel-Schulterdrücken |
| Horizontal ziehen | Last zum Rumpf hin, senkrecht zum Rumpf. | Rudern, Face Pull |
| Vertikal ziehen | Last von oben nach unten zum Körper. | Klimmzug, Latziehen |
| Kniebeuge (Squat) | Knie- und Hüftbeugung, Oberkörper eher aufrecht, Betonung Quadrizeps. | Kniebeuge, Frontkniebeuge, Beinpresse |
| Hüftbeuge (Hinge) | Bewegung aus der Hüfte, Knie wenig gebeugt, Betonung Gesäß und Beinbeuger. | Kreuzheben, RDL, Good Morning, Hip Thrust |
| Ausfallschritt (Lunge) | Einbeinige Kniebeuge mit versetzten Füßen. | Bulgarian Split Squat, Reverse Lunge |
| Tragen (Carry) | Gehen mit Last, Rumpf stabilisiert. | Farmer's Walk, Koffer-Tragen |
| Rotation | Rumpfdrehung gegen Widerstand. | Holzhacker am Kabel |
| Anti-Rotation | Rumpf hält gegen eine drehende Kraft. | Pallof Press |
| Anti-Extension / Rumpfbeuge | Rumpf hält gegen Überstreckung oder beugt aktiv. | Plank, Ab Wheel, Beinheben |
| Isolation Ellbogen, Knie, Sprunggelenk | Eingelenkige Übungen für Arme, Oberschenkel, Waden. | Curls, Trizepsdrücken, Beinstrecker, Wadenheben |

Grundmuster laut Galpin (H2, H3): horizontal und vertikal drücken, horizontal und vertikal ziehen, Kniebeuge, Hüftbeuge. Tragen und Rotation sind ergänzend (**unsicher**, siehe H3).

## c) Übungskatalog

## d) Volumen und Intensität

| Begriff | Definition |
|---|---|
| Satz | Folge von Wiederholungen ohne Pause. |
| Arbeitssatz | Satz mit Trainingswirkung, kein Aufwärmsatz. |
| Harter Satz | Arbeitssatz nahe am Muskelversagen, meist 0 bis 3 RIR. Grundeinheit für Volumen (Nr. 4, 11, 12). |
| Wiederholung (Wdh., Rep) | Eine vollständige Ausführung der Bewegung. |
| Muskelversagen (momentanes) | Keine weitere Wiederholung in sauberer Technik möglich (Nr. 10, 11). |
| RIR (Reps in Reserve) | Wiederholungen, die im Satz noch möglich gewesen wären. 0 RIR entspricht Versagen. |
| RPE (Rate of Perceived Exertion) | Anstrengung auf einer Skala 1 bis 10. Im Krafttraining gilt RPE 10 = 0 RIR, RPE 8 = 2 RIR. |
| Volumen-Last (Tonnage) | Gewicht mal Wiederholungen mal Sätze. Sagt wenig über Hypertrophie, nützlich für Verlauf einer Übung. |
| Wochenvolumen | Harte Sätze pro Muskelgruppe und Woche (Nr. 4, 13). |
| 1RM | Maximalgewicht für genau eine Wiederholung. |
| e1RM (geschätztes 1RM) | Aus Gewicht und Wiederholungen berechnet, zum Beispiel nach Epley. |
| Epley-Formel | e1RM = Gewicht × (1 + Wdh. / 30). Genauer bis etwa 10 Wdh. |
| MV | Maintenance Volume: Volumen, das Muskeln erhält (Nr. 8). |
| MEV | Minimum Effective Volume: kleinste Menge mit messbarem Wachstum (Nr. 8). |
| MAV | Maximum Adaptive Volume: Bereich mit dem besten Fortschritt (Nr. 8). |
| MRV | Maximum Recoverable Volume: größte Menge, von der man sich noch erholt. Individuell und veränderlich (Nr. 8). |
| Progressive Überlastung | Reiz über die Zeit steigern: mehr Gewicht, mehr Wdh., mehr Sätze, größerer Bewegungsumfang oder kürzere Pausen (H2, H3). |
| Deload | Geplante Phase mit weniger Volumen oder Last, um Ermüdung abzubauen (Nr. 8). |
| Periodisierung | Planung von Trainingsphasen mit wechselnden Schwerpunkten, etwa Hubermans monatlicher Wechsel schwer und moderat (H1). |
| Mesozyklus | Block von meist 4 bis 8 Wochen mit steigendem Volumen und anschließendem Deload (Nr. 8). |
| Mechanische Spannung | Kraft auf die Muskelfasern unter Last. Wichtigster Hypertrophie-Reiz (Nr. 9). |
| Metabolischer Stress | Anhäufung von Stoffwechselprodukten, spürbar als Pump (Nr. 9). |
| Gedehnte / verkürzte Position | Gelenkwinkel mit langer bzw. kurzer Muskellänge (H1, Nr. 19). |
| Lengthened Partials | Teilwiederholungen im gedehnten Bereich (Nr. 20). |
| Mind-Muscle-Connection | Bewusstes Ansteuern des Zielmuskels (H6). |
| 3-bis-5-Regel | Kraftschema nach Galpin: 3 bis 5 Übungen, Wdh., Sätze, Minuten Pause, Einheiten pro Woche (H2). |

## e) Ernährung

| Begriff | Definition |
|---|---|
| Kaloriendefizit | Weniger Energie aufnehmen als verbrauchen. Nötig für Fettabbau (Nr. 17). |
| Kalorienüberschuss | Mehr aufnehmen als verbrauchen. Begünstigt Muskelaufbau (Nr. 14, 17). |
| Erhaltungsbedarf / TDEE | Total Daily Energy Expenditure: Gesamtverbrauch pro Tag aus Grundumsatz, NEAT, Training und Verdauung. |
| Grundumsatz (BMR, RMR) | Energieverbrauch in Ruhe für Grundfunktionen. |
| Katch-McArdle-Formel | Grundumsatz = 370 + 21,6 × fettfreie Masse in kg. Braucht Körperfettanteil, berücksichtigt also Muskelmasse. |
| Thermischer Effekt (TEF) | Energie für die Verdauung. Bei Protein ca. 20 bis 30 % (H4). |
| NEAT | Non-Exercise Activity Thermogenesis: Energie für Alltagsbewegung ohne Sport. Sinkt im Defizit oft unbemerkt (H4). |
| Stoffwechselanpassung | Sinkender Verbrauch im Defizit über das durch Gewichtsverlust erklärte Maß hinaus (H4). |
| Proteinbedarf | Für Muskelaufbau 1,6 bis 2,2 g/kg Körpergewicht (Nr. 2, 16). Im Defizit bei Schlanken 2,3 bis 3,1 g/kg fettfreie Masse (Nr. 6, 7, 17). |
| Leucin-Schwelle | Menge Leucin pro Mahlzeit, ab der die Muskelproteinsynthese maximal anspringt. ISSN: 700 bis 3.000 mg pro Portion (Nr. 16, H4). |
| Proteinverteilung | Aufteilung auf Mahlzeiten. 0,4 g/kg pro Mahlzeit über mindestens 4 Mahlzeiten (Nr. 5) oder mindestens 2 bis 3 proteinreiche Mahlzeiten (H4). |
| Muskelproteinsynthese (MPS) | Aufbau neuer Muskelproteine. Steigt nach Protein und Training (H3). |
| Anaboles Fenster | Zeitraum nach dem Training für Nährstoffe. Breiter als früher angenommen (H3, Nr. 6). |
| Kohlenhydrat-Timing | Kohlenhydrate um das Training legen. Kleiner Effekt im Vergleich zu Gesamtmenge (Nr. 6, 14). |
| Refeed | Ein bis zwei Tage mit Kalorien auf Erhaltung, meist über Kohlenhydrate, innerhalb einer Diät. Evidenz schwach. |
| Diet Break | Pause von ein bis zwei Wochen auf Erhaltung während einer längeren Diät. Evidenz begrenzt. |
| Energieverfügbarkeit | Energieaufnahme minus Trainingsverbrauch, bezogen auf fettfreie Masse. Zu niedrig schadet Hormonen und Muskeln. |
| Zeitlich begrenztes Essen (TRE) | Essen nur in einem Zeitfenster. Bei gleichen Kalorien kein Vorteil für Fettabbau (H4, Nr. 17). |
| Glykämische Antwort | Anstieg des Blutzuckers nach einer Mahlzeit. Individuell verschieden (H7). |
| CGM | Continuous Glucose Monitor: Sensor, der den Gewebezucker laufend misst (H7). |
| Glykämischer Index | Mittlere Blutzuckerwirkung eines Lebensmittels im Vergleich zu Glukose. Bildet individuelle Antworten schlecht ab (H7). |
| Abnahmerate | Gewichtsverlust in Prozent Körpergewicht pro Woche. Für Muskelerhalt 0,5 bis 1 % (Nr. 6). |

## f) Messgrößen

| Begriff | Definition |
|---|---|
| Körpergewicht, 7-Tage-Schnitt | Gleitender Mittelwert der Tageswerte. Gleicht Schwankungen durch Wasser und Darminhalt aus. |
| Körperfettanteil (KFA, %) | Anteil der Fettmasse am Körpergewicht. |
| Fettmasse | Körpergewicht × KFA. |
| Fettfreie Masse (FFM, LBM) | Körpergewicht minus Fettmasse. Enthält Muskeln, Wasser, Organe, Knochen. Steigt nicht nur durch Muskelaufbau. |
| FFMI | Fat-Free Mass Index: fettfreie Masse in kg geteilt durch Körpergröße in m zum Quadrat. Galpin nutzt ihn als Fitnesstest (H3). |
| Taillenumfang | Umfang auf Nabelhöhe oder an der schmalsten Stelle. Einfacher Verlaufswert für Bauchfett. |
| Taillen-Größen-Verhältnis | Taille geteilt durch Körpergröße. Unter 0,5 gilt als günstig. |
| DEXA | Dual-Röntgen-Absorptiometrie. Misst Fett, fettfreie Masse und Knochen getrennt. Genaueste verbreitete Methode, aber auch abhängig von Hydration und Mahlzeit. |
| BIA | Bioelektrische Impedanzanalyse, zum Beispiel in Körperfettwaagen. Schätzt über elektrischen Widerstand. |
| BIA-Fehler | Stark abhängig von Wasserhaushalt, Mahlzeit, Training, Tageszeit und Hauttemperatur. Einzelwerte können um mehrere Prozentpunkte abweichen. Für Verläufe nur unter gleichen Bedingungen und als Mittelwert nutzbar (Nr. 1 diskutiert die Grenzen der Messmethoden). |
| Hautfaltenmessung (Caliper) | Schätzt KFA über Hautfalten. Abhängig von der messenden Person. |
| Umfänge | Oberarm, Oberschenkel, Brust. Indirekter Hinweis auf Muskelzuwachs. |
| Fortschrittsfotos | Gleiche Pose, gleiches Licht. Ergänzen Zahlen bei Recomposition, wenn das Gewicht stabil bleibt. |
| Griffkraft | Mit Handdynamometer gemessen. Marker für Gesundheit und Erholung (H3, H6). |
| HRV, Ruhepuls | Herzratenvariabilität und Ruhepuls als Erholungsmarker (H3). |
